# Open Source Guide

## Recommended Repository Name

`facebook-ad-creative-skill`

Alternative:

`meta-ads-image-skill`

## What To Publish

Publish the full repository:

- `.claude/skills/facebook-ad-creative`
- `examples`
- `data`
- `docs`
- root `README.md`
- `LICENSE`

## GitHub Topics

Recommended topics:

- `ai-skill`
- `facebook-ads`
- `meta-ads`
- `ecommerce`
- `image-generation`
- `prompt-engineering`
- `creative-testing`
- `advertising`

## Contribution Areas

- Add industry packs.
- Add more layout templates.
- Add prompt lint rules.
- Add real image API adapters.
- Add localization packs for non-English markets.
- Add generated creative scoring examples.

## Compliance

Contributors should avoid templates that imply:

- guaranteed health, financial, or body outcomes
- sensitive personal attributes
- fake reviews or fake endorsements
- guaranteed advertising performance
- unauthorized competitor claims
