# Model Adapters

The skill outputs a universal image prompt plus model-specific versions.

## GPT Image 2

The GPT Image 2 prompt emphasizes:

- precise commercial composition
- realistic product proportions
- clean visual hierarchy
- readable typography when text is requested
- mobile-first ad clarity

Use this version when typography, layout instruction following, and polished commercial rendering matter.

## Nano Banana

The Nano Banana prompt emphasizes:

- direct visual instructions
- distinct scene and style cues
- natural commercial lighting
- simple text overlay
- concise negative constraints

Use this version when you want fast creative exploration with strong visual variety.

## Text Guidance

Image models can still make typography mistakes. For production ad work, generate both:

- a no-text or light-text image
- a design brief for manual text overlay in Canva, Figma, Photoshop, or an ad creative tool

For batches, avoid putting too much copy into every image. Let some variants test pure visual hooks.
