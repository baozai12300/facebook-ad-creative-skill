# Facebook Creative Best Practices

Use these as practical creative heuristics:

- Show product value within the first glance.
- Make the target use case visually obvious.
- Keep one clear visual focal point.
- Make the product large enough for mobile feed.
- Keep text overlay short and readable.
- Avoid crowded backgrounds.
- Use different creative hypotheses in a batch, not cosmetic variations.
- Pair product clarity variants with UGC, lifestyle, proof, and offer variants.
- For cold audiences, make the problem and benefit obvious.
- For warm audiences, use feature clarity, comparison, or proof.
- For hot audiences, address offer, urgency, shipping, bundle, guarantee, or final objections.

## Placement Notes

- Feed: 4:5 is a strong default for mobile.
- Story/Reels: 9:16, central safe area, minimal text.
- Square: useful for catalog-style tests and broad reuse.
