# Variation Strategy

Batch generation must test meaningfully different creative hypotheses, not cosmetic permutations.

## Variation Priority

Vary in this order:

1. dominant creative angle
2. use moment / buyer problem
3. layout family
4. scene
5. camera language
6. visual DNA / production level
7. copy strategy
8. color mood

Changing only color, background, props, or camera crop does not count as a new creative hypothesis.

## Controlled Dimensions

- audience hypothesis
- awareness stage
- pain point / desire
- dominant angle
- use moment
- scene
- visual style / DNA
- composition / layout
- product scale
- main visual element
- copy density
- color mood
- camera language

## Hard Rules

### 4-image batch

- every creative must have a distinct dominant angle where appropriate
- use at least 3 different layout families
- each creative must differ from every other creative in at least 3 major dimensions
- include at least 1 direct product-clarity creative
- include at least 1 lifestyle / real-use / UGC creative
- include at least 1 problem/benefit concept

### 8-image batch

- rotate angles before repeating them
- do not use the same layout more than twice unless explicitly A/B testing
- do not repeat the same scene + style + layout combination
- include cold-audience discovery concepts and warmer product-clarity/value concepts
- include proof only when real proof is available
- include offer/value only when the user supplied an offer

## Controlled A/B Mode

If the user explicitly wants A/B testing of one concept, hold most dimensions constant and vary only one or two variables, for example:

- same angle + same layout, different headline
- same angle + same scene, different product scale
- same layout + same copy, UGC vs polished production

Label these as controlled variants so they are not confused with broad creative exploration.

## Diversity Check

Before emitting the batch, compare each pair across:

- angle
- use moment
- layout
- scene
- camera
- visual DNA
- text strategy

If two creatives differ only in superficial styling, revise one at the concept level.

## Output Note

Keep the explanation of how variants differ in the planning object only. Do not inject a sentence such as “this variation differs from…” into the image-generation prompt.
